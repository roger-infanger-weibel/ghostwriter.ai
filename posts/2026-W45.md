## Global

### OpenAI: GPT-6 Cyber vorgestellt
OpenAI stellt GPT-6 Cyber vor, ein Sicherheitsmodell, das ausnutzbare Schwachstellen findet und Fixes entwirft und dabei innerhalb des autorisierten Umfangs bleibt. Für die Sicherheitsarbeit mit Agenten ist relevant, dass der Scope-Bezug explizit Teil des Modells ist.
Quelle: [OpenAI: Introducing GPT-6 Cyber](https://openai.com/index/introducing-gpt-6-cyber), 5. November 2026

### OpenAI: Images 2.6
Images 2.6 bringt schnellere Bildgenerierung, GIF-Erstellung, präzisere Bearbeitung und neue API-Steuerungen in ChatGPT, Codex und der API.
Quelle: [OpenAI: Introducing Images 2.6](https://openai.com/index/introducing-images-2-6), 4. November 2026

### Anthropic API: Message Threads (Beta)
Message Threads sind in der Messages API als Beta verfügbar (Beta-Header `message-threads-2026-08-12`). Die API hält die Konversation serverseitig, spätere Anfragen senden nur neue Nachrichten. Ein Thread läuft 5 Minuten nach der letzten Anfrage ab und wird spätestens 1 Stunde nach letzter Nutzung gelöscht.
Quelle: [Claude API Release Notes](https://platform.claude.com/docs/en/release-notes/overview), 2. November 2026

### Anthropic: IP-Allowlist in der Claude Console (Beta)
Organisationen können in der Claude Console eine IP-Allowlist einrichten; Anfragen von nicht gelisteten Adressen werden abgelehnt. Pro Organisation sind bis zu 1,000 IPv4- und IPv6-Adressen oder CIDR-Bereiche möglich. Zusätzlich können Admins per Admin API (Beta) ein Claude-Enterprise-Mitglied überall abmelden.
Quelle: [Claude API Release Notes](https://platform.claude.com/docs/en/release-notes/overview), 5. November 2026

## Für mich relevant

Die serverseitigen Message Threads der Claude API könnten meine Claude-Config für mehrstufige Agenten-Abläufe vereinfachen, da nur neue Nachrichten gesendet werden müssen; die kurze Ablaufzeit von 5 Minuten ist dabei zu beachten. Die IP-Allowlist ist eine konkrete Massnahme gegen Datenabfluss und für das CAS-Projekt als Beispiel für Zugriffskontrolle bei agentischen Systemen nutzbar.
