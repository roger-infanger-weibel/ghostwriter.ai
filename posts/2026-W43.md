# KI-Wochenrückblick – KW 43 / 2026

Zeitraum: 19.–25. Oktober 2026

## Global

### Anthropic: API-Version 2026-10-21 und neue SDK-Major-Versionen
Anthropic hat die API-Version 2026-10-21 veröffentlicht. Die neuen Client-SDKs und die `ant` CLI senden diese Version standardmässig: Python SDK 2.0.0, TypeScript SDK 1.0.0, C# SDK 13.0.0, Go SDK 2.0.0, Java SDK 3.0.0, PHP SDK 1.0.0, Ruby SDK 2.0.0 und `ant` CLI 2.0.0. Die neuen Versionen enthalten laut Release Notes Breaking Changes, die nicht von der API-Version abhängen, und stehen neu unter Apache 2.0 statt MIT-Lizenz.
Quelle: [Claude Platform Release Notes](https://docs.claude.com/en/release-notes/overview), 21. Oktober 2026

### Anthropic: Claude Models on Google Cloud (Anthropic managed)
Anthropic hat die von Anthropic betriebene Claude API gestartet, die über ein Google-Cloud-Projekt erreichbar ist. Der Zugriff wird über Google Cloud IAM gesteuert, die Abrechnung läuft über den Google Cloud Marketplace. Fast mode ist für Claude Opus 5.5 auf diesem Angebot verfügbar.
Quelle: [Claude Platform Release Notes](https://docs.claude.com/en/release-notes/overview), 22. Oktober 2026

### Anthropic: Agent Skills an die Agentic AI Foundation übergeben
Anthropic übergibt den offenen Standard Agent Skills an die Agentic AI Foundation. Laut Anthropic haben mehr als 70 Agent-Plattformen, darunter ChatGPT, Cursor, GitHub Copilot und VS Code, den Standard seit seiner Veröffentlichung im Dezember 2025 integriert.
Quelle: [Anthropic News](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation), 22. Oktober 2026

## Europa

### Mistral AI: Voxtral 3 mit Voice Agent SDK
Mistral hat Voxtral 3 veröffentlicht, laut Titel der Ankündigung ein Voice Agent SDK sowie Speech-Modelle in über 50 Sprachen. Das Demo auf der Seite zeigt einen Sprach-Agenten, der per Tool Call einen Arzttermin bucht.
Quelle: [Mistral – Voxtral 3](https://mistral.ai/news/voxtral-3/), 20. Oktober 2026
