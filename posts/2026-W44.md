# KI-Wochenrückblick – KW 44 / 2026

Zeitraum: 26. Oktober–1. November 2026

## Global

### Google: Computer Use in der Gemini API allgemein verfügbar (GA)
Google hat das Computer-Use-Tool über die Interactions API und die GenerateContent API hinweg zur allgemeinen Verfügbarkeit (GA) freigegeben.
Agenten, die Oberflächen bedienen, sind damit nicht mehr an eine Preview gebunden. Wegen des Zugriffs auf Bildschirminhalte bleibt Agent Safety (Prompt Injection, Datenabfluss) relevant.
Quelle: [Gemini API Release Notes](https://ai.google.dev/gemini-api/docs/changelog), 30. Oktober 2026

### Google: Generate Content API speichert Anfragen bei neuen Projekten standardmässig
Neue Projekte im bezahlten Tarif, die die Generate Content API (`generateContent`, `streamGenerateContent`, `batchGenerateContent`) nutzen, speichern Anfragen jetzt standardmässig (`store=true`), analog zur Interactions API. Bestehende Projekte behalten ihre Einstellung. Opt-out per `store=false` pro Anfrage oder über das Logs-and-Datasets-Dashboard.
Quelle: [Gemini API Release Notes](https://ai.google.dev/gemini-api/docs/changelog), 26. Oktober 2026

### Anthropic: Fast Mode für Claude Opus 4.8 deprecated
Der Fast Mode für Claude Opus 4.8 ist deprecated; die Entfernung erfolgt am 30. November 2026. Danach liefern Anfragen an `claude-opus-4-8` mit `speed: "fast"` einen Fehler. Anthropic empfiehlt die Migration auf Claude Opus 5.5.
Quelle: [Claude Platform Release Notes](https://docs.claude.com/en/release-notes/overview), 30. Oktober 2026

### OpenAI: Erkennung von Fehlausrichtung bei Frontier-Modellen
OpenAI beschreibt, wie mit mehrschichtigem Monitoring Fehlausrichtung (Misalignment) und nicht autorisiertes Agentenverhalten erkannt werden, damit Verantwortliche eingreifen können, bevor Vorfälle eskalieren.
Quelle: [OpenAI](https://openai.com/index/how-we-detect-frontier-model-misalignment), 29. Oktober 2026

## Schweiz

### Bundesrat: KI-Regulierung auf zwei Ebenen
Der Bundesrat will die KI-Regulierung auf zwei Ebenen umsetzen: Der Bund bereitet rechtlich verbindliche Massnahmen zur Umsetzung der KI-Konvention des Europarats vor, ergänzend sollen Leitlinien und freiwillige Selbstverpflichtungen gelten. Er hat am 28. Oktober den Stand der Arbeiten und erste Ergebnisse des Bakom zur Kenntnis genommen; eine Bestandsaufnahme soll zeigen, wo Behörden KI einsetzen und wo Risiken bestehen. (Nur der frei zugängliche Teaser des Artikels wurde gelesen.)
Quelle: [inside-it.ch](https://www.inside-it.ch/so-will-der-bund-den-umgang-mit-ki-regeln-20261028), 28. Oktober 2026

## Für mich relevant

Die neue Standardspeicherung der Generate Content API betrifft jedes Projekt, das Gemini mit Parkleitsystem-Daten anspricht: Für neue Projekte sollte `store=false` bewusst geprüft werden. Die Deprecation des Opus-4.8-Fast-Mode ist für die Claude-Config relevant, falls dort noch `claude-opus-4-8` mit `speed: "fast"` hinterlegt ist. Die Bundesrats-Linie zur KI-Konvention ist ein Anknüpfungspunkt für das CAS-Projekt «Innovation Management».
